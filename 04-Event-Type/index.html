Topic 04

JavaScript Event Types

Window events, form events, keyboard events and mouse events.

What is an Event?

An event means that something happened in the browser.

User does something → Event happens → JavaScript reacts
01

Window Events

Events related to the browser window or the entire page.

load

Happens when the page and its resources finish loading.

Waiting...

resize

Happens when the browser window changes size.

Resize the window.

scroll

Happens while the user scrolls the page.

Scroll position: 0

beforeunload

Can warn the user before leaving a page.

unload

Deprecated. Avoid using it for modern application logic.

02

Form Events

Interact with the form and watch which events happen.

focus: Waiting

blur: Waiting

input: Waiting

change: Waiting

submit: Waiting

reset: Waiting

Important: input fires while the value changes. change happens when the change is committed.
03

Keyboard Events

Click the input and press keyboard keys.

keydown: Waiting

keyup: Waiting

keypress: Deprecated — use keydown or keyup .
