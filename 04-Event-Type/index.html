Topic 04

JavaScript Event Types

Window events, form events, keyboard events and mouse events.

What is an Event?

An event means that something happened in the browser.

User does something → Event happens → JavaScript reacts
01

Window Events

Events related to the browser window or the entire page.

load

Happens when the page and its resources finish loading.

Waiting...

resize

Resize the browser window.

Resize the window.

scroll

Scroll this page.

beforeunload

Can warn the user before leaving a page with unsaved work.

unload

Deprecated. Do not use it for modern application logic.
