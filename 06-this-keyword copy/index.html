this Keyword

Understanding this

Inside an object method, this refers to the object that is calling the method.

Student Object

Name: -

Age: - 

const student = {

    name: "Ahmad",
    age: 23,

    showInfo: function () {

        console.log(this.name);
        console.log(this.age);

    }

};

student.showInfo();
Remember:

In this example:

this.name

means:

student.name
