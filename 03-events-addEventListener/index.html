Topic 03

Events & addEventListener()

An event means that something happened. JavaScript can listen for that event and run a function.

Event Something happened
→
Listener Wait for the event
→
Function React to it

Demo Box

Color Box

Choose one of the examples below.

1. Inline onclick

The function is called directly from the HTML element.

<button onclick="inlineClick()">
    Click Me
</button>

2. addEventListener()

JavaScript listens for the click event and then calls the function. 

listenerBtn.addEventListener(
    "click",
    changeColor
);

3. changeColor vs changeColor()

changeColor

This is the function itself.

Give it to JavaScript so it can run later.

changeColor()

This calls the function immediately.

// Correct

button.addEventListener(
    "click",
    changeColor
);

4. Function With Parameter

If the function needs an argument, place the call inside another function. 

argumentBtn.addEventListener(
    "click",
    function () {

        changeToColor("tomato");

    }
);

5. Multiple Listeners

One event can have more than one listener.

multipleBtn.addEventListener(
    "click",
    changeBackground
);

multipleBtn.addEventListener(
    "click",
    moveBox
);

Listener 1 changes the box color. Listener 2 moves the box.
